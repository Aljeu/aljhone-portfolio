> Good digital work makes the next step clear. I shape the structure, design the interface, and build the experience around what people need to do.

- **Landing pages and business websites** — clear positioning, useful content structure, responsive interfaces, and direct paths to inquire or take action.

- **Product design and frontend engineering** — from early structure and interaction decisions through implementation and refinement.

Aljhone is especially interested in helping local businesses and individual clients establish a stronger digital presence, and is open to projects with teams and organizations that need a considered design-and-build partner.

## How I work

1. **Define** — agree on the audience, goals, scope, and content.
2. **Design** — shape the structure, interface, and visual direction.
3. **Build** — implement the agreed experience and review how it behaves.
4. **Refine** — resolve revisions and prepare the handover.

## About this portfolio site

This is a responsive portfolio built with semantic HTML, CSS, and JavaScript, using Vite for local development and production builds. The home page presents selected work, an introduction, services, process, and a direct contact path. Visitors can browse the project archive, open project details, and choose among Mono, Crimson, and Warm palettes in light or dark mode.

The visual identity pairs bold Archivo headlines with IBM Plex Sans body text. A continuously animated shader and a silhouette form the hero artwork; palette and mode changes adapt the scene. The interface includes keyboard navigation, visible focus, reduced-motion support, responsive layouts, and accessible carousel announcements.

### Technology

- Vite, HTML, CSS, and modern JavaScript
- Three.js, React Three Fiber, and ShaderGradient for the hero scene
- Archivo and IBM Plex Sans, self-hosted through Fontsource under the SIL Open Font License
- A small JSON project catalog that drives the carousel, archive, and project details

## Run locally

Use Node.js 22 or a compatible current LTS release.

```bash
npm install
npm run dev
```

To create and preview the production build:

```bash
npm run build
npm run preview
```

## Add a project

Edit [`src/data/projects.json`](src/data/projects.json) and add a project entry. Put its cover image under `public/projects/`, use a descriptive filename and useful alt text, and set its category to `Websites`, `Web apps`, or `Apps`. Keep summaries specific and concise; add repository and demo URLs only when they are public and working. Set unavailable links to `null`.

All non-placeholder projects appear in the selected-work carousel, archive, and detail view. A placeholder should remain clearly hypothetical with `placeholder: true`; do not imply client work, results, or a launch that has not happened.
